# Changelog

## [v0.0.1] — обязательная авторизация и защита от утечки паролей

Первый релиз ультралегкого прокси-контейнера для обхода ограничений встроенного Web-Proxy MikroTik RouterOS.

### Изменения

- **Обязательная HTTP Basic авторизация:** запросы без валидного заголовка немедленно блокируются статусом HTTP 407.
- **Защита от утечки учетных данных:** заголовок `Proxy-Authorization` вырезается из запроса перед отправкой на upstream-сервер.
- **Двухформатная сборка:** поддержка OCI-контейнеров для RouterOS 7.21+ и классического Docker v1.2 для RouterOS 7.4–7.20.
