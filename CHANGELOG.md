# Changelog

## [v0.1.0] — многопользовательский режим, epoll и полный аудит безопасности

Крупная переработка ядра: прокси переведён на событийную модель, добавлена
поддержка множества учётных записей и построен полный харнесс проверок
(санитайзеры, Valgrind, фаззинг, сквозные тесты).

### Безопасность и устойчивость

- **Событийный `epoll`-цикл вместо потока на соединение.** Снят вектор
  исчерпания памяти (ранее каждое соединение создавало поток со стеком 64 КБ без
  ограничения их числа). Добавлен лимит `MAX_CONN`.
- **Анти-slowloris.** Дедлайн на приём заголовка (`HEADER_TIMEOUT_MS`) и таймаут
  простоя (`IDLE_TIMEOUT_MS`); «подвисшие» соединения принудительно закрываются.
- **Защита от перебора.** Троттлинг по IP после серии неудачных попыток входа.
- **Удаление всех `Proxy-Authorization`** (а также `Proxy-Connection`) из запроса
  перед отправкой на upstream — не только первого заголовка.
- **Строгий разбор конфигурации** (`strtol` вместо `atoi`, валидация IPv4 и
  портов) и очистка секретов из окружения (`PROXY_PASS`, `PROXY_USERS`) после
  старта.
- **Потокобезопасность.** `localtime_r` в логах, учётная таблица под rwlock,
  атомарный счётчик соединений — проверено ThreadSanitizer.
- **Корректное завершение соединений** (half-close/`shutdown`) без потери данных.

### Возможности

- **Множество пользователей:** `PROXY_USERS` (список) и `PROXY_USERS_FILE`
  (файл с горячей перезагрузкой при изменении). Сверка — в постоянном времени.
- **Масштабирование на многоядерных CCR** через `SO_REUSEPORT` и `WORKERS`.
- **Веб-конфигуратор** получил поле «Дополнительные пользователи» и экранирует
  все пользовательские значения (защита от инъекций в RouterOS-скрипт).

### Харнесс и CI

- `Makefile` с целями `unit`, `integration`, `integration-tsan`, `valgrind`,
  `fuzz`, `lint`, `size`, `ci`.
- Модульные тесты на C, сквозные тесты на Python (mock-upstream, проверка
  отсутствия утечки учётных данных), libFuzzer по парсерам.
- Отдельный workflow `ci.yml`; релиз (`build.yml`) публикуется только после
  прохождения полного гейта.
- Исправлен путь к артефактам в `tests/test_archive_compatibility.sh`.

## [v0.0.1] — обязательная авторизация и защита от утечки паролей

Первый релиз ультралегкого прокси-контейнера для обхода ограничений встроенного Web-Proxy MikroTik RouterOS.

### Изменения

- **Обязательная HTTP Basic авторизация:** запросы без валидного заголовка немедленно блокируются статусом HTTP 407.
- **Защита от утечки учетных данных:** заголовок `Proxy-Authorization` вырезается из запроса перед отправкой на upstream-сервер.
- **Двухформатная сборка:** поддержка OCI-контейнеров для RouterOS 7.21+ и классического Docker v1.2 для RouterOS 7.4–7.20.
